# Waystroke — одностраничный сайт-портфолио

Одностраничная витрина студии одного веб-разработчика: тёплый светлый фон,
выразительная типографика, тёмная секция «Дизайн» и один лаймовый акцент
(`#C8F054`). Мотив — тонкая линия, похожая на мазок кисти и путь.

## Стек

- **Angular 22.2.0** (стабильный релиз, standalone-компоненты, zoneless)
- Обычный CSS без UI-библиотек, шрифты локально через `@fontsource`
  (Inter 400–700, Playfair Display italic для акцентной строки)
- Без бэкенда и без внешних сервисов, кроме Cal.com (эмбед записи) и Telegram

## Команды

```bash
npm install        # зависимости
npm start          # дев-сервер: http://127.0.0.1:4200
npm run build:prod # production-сборка в dist/waystroke-studio/browser
npm run serve      # статический сервер собранного варианта (порт из PORT, по умолчанию 3000)
npm test           # unit-тесты (vitest)
```

## Секция «Дизайн»

Секция «Разные задачи. Разный характер.» — живая витрина того, как выглядят
**шесть независимых концептов для шести разных ниш**. Это **концепты, а не
клиентские проекты**: отзывы, клиенты, цифры результатов и ссылки на «готовые
проекты» к демо не придумывались.

Три пары сравнения:

| Пара | Концепты | Разный характер |
| --- | --- | --- |
| Музыка / Beauty | «СДВИГ» ↔ «miora» | чёрный фон, кислотный лайм, хром и винил против слоновой кости, антиквы и сетки товаров |
| Авто / Кофе | «ТОЧКА МОТОР» ↔ «крошка» | почти чёрный герой, наклонный гротеск и красный акцент против сливочных тонов, скруглений и меню с ценами |
| Fintech / Art | «saldo» ↔ «ВНЕ РАМКИ» | светлый дашборд с карточками и диаграммой против бумажного постера с крупным чёрным титулом |

- **«СДВИГ»** — музыкальный лейбл: заголовок «Звук вне правил.», обложки
  и релизы нарисованы только CSS/SVG, внешних картинок нет;
- **«miora»** — косметика: тёплая слоновая кость, крупная антиква, чипсы
  и витрина из трёх позиций;
- **«ТОЧКА МОТОР»** — автосервис: фото покрасочной камеры под затемняющей
  шторкой, скошенный заголовок «Точность, в каждой детали.», красный CTA и
  светлая полоса услуг 01 / 02 / 03 со штриховыми иконками;
- **«крошка»** — кофейня: антиква, фотография справа, стикер «свежая обжарка»
  и горизонтальное «Меню дня» с ценами;
- **«saldo»** — финприложение: левая панель, баланс со спарклайном, карта,
  кольцевая диаграмма расходов, операции и цели; все магазины и суммы вымышлены;
- **«ВНЕ РАМКИ»** — арт-выставка: бумага, плотный чёрный титул, рамка с
  геометрией, выходящей за её край, и программа разделов с куратором.

Каждый концепт лежит в своём файле (`concepts/<имя>.*`), общий только контракт:
корень `.mock` заполняет слой целиком, размеры считаются от контейнера через
`clamp()`/`cqw`, а на узком контейнере (≤ 700 px) container query складывает
макет в «мобильную версию». Оба слоя лежат в одной сетке (ячейка `1/1`), и
контейнер принимает высоту большего: ползунок не сжимает половины, а открывает
их обрезкой (`clip-path: inset()` на верхнем слое).

Механика сравнения (`design-demo.*`):

- над сценой — переключатель из трёх пар (кнопки с `aria-pressed`), при смене
  пары граница предсказуемо возвращается на 50 %;
- Pointer Events: нажатие точно по бегунку **и** в любом месте сцены сразу
  ставит границу и продолжает drag; мышь, касание и стилус работают одинаково,
  используется `setPointerCapture(pointerId)`, движение учитывает только
  активный `pointerId`, а `pointerup`/`pointercancel`/`lostpointercapture`
  корректно завершают жест (при `pointercancel` граница откатывается к
  значению на момент нажатия);
- drag продолжается за пределами сцены, значение клампится в 0…100;
- hit-area бегунка ≥ 44 px и совпадает с видимой линией, курсор `col-resize`,
  у рамки `touch-action: pan-y`, у бегунка `none` — вертикальная прокрутка
  страницы на телефоне не блокируется;
- изображения, декоративные слои и текст внутри концептов не перехватывают
  события (`pointer-events: none`, `draggable="false"`, `user-select: none`):
  нативный drag картинок невозможен, выделение текста не мешает;
- клавиатура и скринридер: `role="slider"`, `tabindex="0"`, актуальные
  `aria-valuemin/max/now`, `aria-valuetext`, `aria-label`, подсказка через
  `aria-describedby`, стрелки ±2 %, `Shift`+стрелки ±10 %, `PageUp/PageDown`,
  `Home/End` и заметный `:focus-visible`.

## Превью ссылки и индексация

Картинка для ссылок — `public/images/og-waystroke.png`, ровно **1200×630, PNG**
(собрана из тех же токенов и шрифтов Inter/Playfair, что и сайт: фон `#ece9df`,
тёмный текст, лаймовый акцент `#c8f054`, фирменный мазок линии). Читается и в
маленьком превью Telegram — проверено на уменьшении до 420 px и 200 px.

В `<head>` (`src/index.html`):

- `link rel="canonical"` → `https://waystroke.online/`;
- `meta name="robots"` → `index, follow, max-image-preview:large`;
- Open Graph: `og:type=website`, `og:site_name=Waystroke`, `og:locale=ru_RU`,
  `og:title`, `og:description`, `og:url=https://waystroke.online/`,
  абсолютный `og:image` + `og:image:type/width/height/alt`;
- Twitter Card: `summary_large_image` (+ `twitter:title/description/image`).

Все URL в метаданных абсолютные и ведут на `https://waystroke.online` — с
`<base href="/">` относительные пути в превью ломались бы.

- `public/robots.txt` — `User-agent: *`, `Allow: /`, ссылка на sitemap;
- `public/sitemap.xml` — единственный реально существующий адрес
  `https://waystroke.online/` (сайт одностраничный, якорей и роутинга нет,
  выдуманных маршрутов в карте нет).

## Навигация без якорей

Пункты меню — это `<button>` без `href`: клик плавно скроллит страницу к секции
и ставит на неё фокус (`focus({ preventScroll: true })`), **URL не меняется** —
в адресной строке нет `#top`, `#design`, `#services`. Логотип возвращает к
позиции 0 без перезагрузки. Учтены фиксированная шапка (через `scroll-padding-top`),
закрытие мобильного меню по Escape (фокус возвращается на кнопку меню)
и `prefers-reduced-motion` (скролл становится мгновенным).

## Деплой

Хостинг — **Cloudflare Pages** (бесплатный тариф), проект `waystroke`,
адрес: <https://waystroke.pages.dev>

- Источник — GitHub `MindStyle1/Waystroke`, ветка `main`: каждый push в `main`
  собирается и публикуется автоматически.
- **Build command**: `npm run build`
- **Build output directory**: `dist/waystroke-studio/browser`
- **Root directory**: корень репозитория
- `.nvmrc` поднимает Node до 22.23.2 — облачный образ по умолчанию даёт 22.16.0,
  а Angular 22 требует ≥ 22.22.3.
- **SPA-fallback**: `postbuild` кладёт копию `index.html` в `404.html`, поэтому
  прямое открытие любого адреса рендерит приложение. Catch-all-правило
  `/* /index.html 200` в `_redirects` Cloudflare отклоняет собственной валидацией
  («infinite loop detected»), а `/* /404.html 200` на практике закольцовывает
  ответы (308 → `/404` → …) — поэтому используется только `404.html`.
- Домен `waystroke.online` переводится на NS Cloudflare
  (`dante.ns.cloudflare.com` / `meera.ns.cloudflare.com`): в зоне уже есть
  CNAME `apex` и `www` → `waystroke.pages.dev` (proxied), MX/TXT Timeweb
  сохранены, правило `www → apex` настроено. До смены NS у регистратора
  (`pdr ltd. d/b/a publicdomainreg`) домен открывает парковочную страницу,
  а привязка Pages остаётся в статусе `pending`.

## Проверено

- Desktop 1440×1000 и mobile 390×844: без горизонтальной прокрутки и наложений
- Навигация: URL всегда без хэша, шапка не перекрывает заголовки секций
- Секция «Дизайн»: три пары переключаются, названия концептов пары над сценой
  обновляются, при смене пары граница возвращается на 50 %
- Ползунок (реальные Pointer Events, Playwright + CDP touch):
  drag ровно за центр бегунка 50 → 20 → 80, продолжение жеста за пределами
  сцены, клик в точке 25 % и 75 % сразу двигает границу, координата видимой
  линии совпадает с вычисленным процентом (расхождение 0 px), клавиатура
  (стрелки ±2 %, `Shift` ±10 %, `PageUp/PageDown`, `Home/End`,
  `:focus-visible`), стилус, вертикальный свайп по макету скроллит страницу
  и откатывает границу, hit-area бегунка 44–56 px
- Внутренние элементы концептов не перехватывают события: у картинок
  `draggable="false"`, `dragstart` отменяется, текст не выделяется
- ARIA: `role="slider"`, `aria-valuenow/min/max`, `aria-valuetext`, подсказка
  через `aria-describedby`
- Telegram: две ссылки на `https://t.me/waystroke` с ником `@waystroke`
- `prefers-reduced-motion: reduce` — анимации отключаются, всё видно сразу
- Календарь Cal.com загружается (и в десктопном, и в мобильном виде)
- Продакшен-сборка проходит без предупреждений, ошибок в консоли нет
- Живой сайт <https://waystroke.pages.dev>: `/` → 200, js/css/svg → 200,
  неизвестный путь отдаёт оболочку приложения (SPA-fallback)
